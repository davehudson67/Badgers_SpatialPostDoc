# Sources used to assemble this project

This project combines the previous `NewBadgers` folder, the reorganised spatial-CMR scripts, and useful material from the June 2026 `BadgersLargeGrant` snapshot.

The active baseline model is the corrected M0a–M0c script created after reviewing the earlier model bank. Older scripts are retained only as references or future extensions. The `BadgersLargeGrant` snapshot contributed processed model inputs, source GIS files, landscape matrices, historical outputs, and its model-history notes.

Historical outputs were generated by earlier model versions and should not be treated as results from the corrected baseline.
